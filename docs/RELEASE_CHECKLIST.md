# Windows 发布前验收单

本次未完成下列 Windows 实机项目。**源码/离线测试通过不等于成品 EXE 已通过。** 不自动创建系统任务、不上传日志或密钥。

- [ ] 在干净 Windows 10/11 x64 以普通用户运行打包后的整个 NewsDesk 目录，无 Python 预装也能打开本机界面
- [ ] 首次启动、中文路径、带空格路径、重启恢复、重复启动阻止、端口占用、窗口关闭均正常
- [ ] 原站真实可见文章采集、刊发日期/署名/标题核对、整页截图可读；至少五家各一篇；验证码、拒访、超时、站点改版不误报成功
- [ ] 实际最近7天回填并人工复核：每天最多目标5篇，普通报道剔除，重复URL/标题/正文不混入，短缺如实显示
- [ ] 下载两个附件，Excel 可在 Microsoft Excel 打开，按日期排序，原文链接可用，截图 ZIP 文件夹/manifest 对得上，无缺图冒充成功
- [ ] 用本人测试邮箱明确启用：SSL 与 STARTTLS 各一个真实服务（如可用）、附件大小拒绝、密码错误、网络断开、发送超时不重复
- [ ] 使用有余额的本人 API 账号：真实兼容接口、次数上限、无效模型、无效Key；反馈先预览、取消不生效、应用后重启仍生效
- [ ] Windows 凭据管理器保存与读取；不落明文到数据库/日志/导出；改 API 或 SMTP 目标不会复用旧 Key/密码
- [ ] 在模拟可控时间下检查周四14:00北京边界与Thu–Wed区间；另做一次真实定时唤起；电脑关机/休眠/程序关闭的缺失行为已向用户说明
- [ ] 标准用户浏览器的登录/第三方安全提示、文件下载器、窗口缩放、窄屏与中文字体已核对；不要求关闭防护
- [ ] 发布 ZIP/仓库不含 data、.venv、原新闻全文fixture、截图、邮件配置、用户邮箱、API Key、旧工具用户资料
- [ ] 依赖和 Chromium 许可通知完整；确定仓库、开源协议、产品名和发布者；审核 GitHub Actions 权限与第三方 action 版本
- [ ] 为 Windows 二进制安排签名、杀毒扫描和安装文档；尚未签名时如实标注，不声称通过 SmartScreen 信任

发布前请由维护者确认最终代码、构建产物、许可与上述验收结果。
