# 安全与可靠性边界

- 单用户本机工具，只监听127.0.0.1。Host/Origin/Fetch-Site校验、随机本机会话token、CSP防护。不是公网服务器、多用户授权系统或对同机恶意软件的隔离边界
- 新闻原文/栏目支持内置媒体及用户输入的其他公开媒体域名；拒绝嵌入账号、异常端口和非HTTP(S)。每次请求和重定向检查公网DNS及robots，遇401/403/429不绕过。浏览器主框架导航也校验目标和robots，屏蔽非GET/HEAD、媒体播放及WebSocket，不接受下载
- DNS检查与HTTP/浏览器真正建立连接并非同一条已固定IP的连接：**尚未提供完整DNS重绑定防护或恶意页面网络沙箱保证**。请只运行可信媒体链接和本人确认的API地址；不适合处理攻击者提交的任意网址或暴露到局域网/公网
- 第三方网页JavaScript由隔离的新Chromium上下文运行，无用户浏览器会话；不读取用户已登录浏览器。新闻截图仍受原站脚本、广告和访问规则影响
- API Key绑定确切Base URL，SMTP密码绑定主机/端口/TLS方式/登录账号；API不跟随重定向，不把密钥发到另一个地址。只支持HTTPS API和经过证书校验的邮件TLS
- 密钥仅内存或用户勾选后的Windows凭据管理器，不保存在SQLite/导出/浏览器localStorage，不读取无关环境变量。系统凭据权限仍受本机用户账号和操作系统安全约束
- API反馈只能返回三个经过验证的声明式规则字段，提供差异预览后由用户应用；不执行模型代码，不改安全配置/收件人/定时开关
- SMTP的日期范围/收件人发送键由SQLite BEGIN IMMEDIATE原子占位，防止同一任务并发重复；“已被服务器接受”不等于终端已收到，超时不确定状态禁止自动重发
- 本地数据/普通配置未加密。删除文件、磁盘损坏、媒体改版、历史栏目缺失都会影响结果；请自行备份。本版不自动删除历史资料或静默上传备份
- 新安装及依赖版本上限控制只是基本措施；未进行专业渗透测试、供应链审计或Windows签名审核
