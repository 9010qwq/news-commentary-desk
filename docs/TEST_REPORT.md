- 模拟 SMTP 发送、同日期/收件人防重、原子并发占位、默认关闭外发

## 被环境阻断：完整浏览器和在线应用采集

- 现有 Chromium 原生启动报 `socket() failed: Operation not permitted`；普通与获准的沙箱外运行均相同，没有修改安全策略
- 云端命令环境的媒体域名 DNS 无法解析；程序的公网/robots 检查如实停止，未改成跳过检查来制造成功
- 长驻本机服务从独立云浏览器访问返回连接拒绝；未通过代理、注入、禁用策略等方式绕过

因此本次**未验证**：应用内真实Playwright整页截图、完整每日5篇采集/补采/导出端到端、真实浏览器按钮/下载器/响应式像素效果。已有源码实现和离线测试不能代替这些阶段。
