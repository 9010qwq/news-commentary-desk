# 评论收集台 · 小栈 NewsDesk 0.2

一个给个人使用、可自行分发的本地新闻时评整理工具。打开一个中文页面，设置来源和邮箱，收集原文、截图，按日期导出 Excel 和截图 ZIP。不需要 ChatGPT 订阅；可选的模型 API 由你选择的供应商计费。

**这是试用候选，请区分源码包和 Windows 便携包。** 如果拿到 Release 中的 `NewsDesk-Windows-Portable.zip`，解压整个文件夹后双击 `NewsDesk.exe`，不需要另装 Python；不能只拷贝 exe。如果拿到源码试用包，则使用下方步骤，需要 Python 3.11+，首次会下载依赖与 Chromium。附一键启动脚本、便携版构建脚本和手动 GitHub 构建流程。未在你的电脑部署、未替你开任何定时服务、未发送真实邮件。项目仓库位于 [GitHub 仓库](https://github.com/9010qwq/news-commentary-desk)，具体构建与发布状态以仓库为准。验证边界见 [测试记录](docs/TEST_REPORT.md)。

## Windows 源码包：从这里开始

1. 把整个包解压到自己的文件夹，如 `D:\NewsDesk`。不要覆盖以前的 LocalDesk 或任何已有 data 文件夹。
2. 如果没有 Python 3.11 或以上版本，先从 [Python 官网](https://www.python.org/downloads/windows/)安装，勾选加入 PATH。
3. 双击 **安装与启动.cmd**（也可用英文名 `start_windows.cmd`）。第一次会先询问是否下载 Python 组件与截图浏览器，输入 y 后继续；不下载大模型，不自动设置开机启动。
4. 浏览器会打开 `http://127.0.0.1:8768`。保持启动窗口运行。没有自动打开时手动访问该地址；端口冲突可用 `launch.py --port 8769`。
5. 在“每日采集”选择日期，点“立即采集”。不开 API 也会根据原页明确的快评、时评、社论标签筛选。第一次可先补充一个允许媒体的真实原文链接试采。
6. 打开“采集与发送设置”，按需要启用每日采集和周报邮件。勾选自动邮件并保存即授权本工具按显示的计划向所填邮箱发送。

macOS/Linux 可运行 `sh start_unix.sh`，首次也会询问下载；本次未作这些系统的原生浏览器验收。安全记住密码功能本版只支持 Windows 凭据管理器。

## 日常只需要这个页面

- **每日目标默认合计 5 篇**，不是五家各 5 篇。可调整数量，优先兼顾媒体多样性
- 来源：央视新闻、人民日报、新京报、新华网、澎湃新闻。人民日报优先纸报当天真实评论版，不把人民网原创都算人民日报
- 可补充任意公开媒体的栏目 URL，或按日期粘贴单篇原文 URL。五家内置媒体有专用适配，其他媒体用通用正文和元数据解析，不能识别就报告原因。首版不是任意网站万能爬虫；RSS/搜索引擎/私有登录站点不在本版支持范围
- URL、去掉栏目标签后的标题、完整正文哈希参与去重；相近日期同标题/同正文不会重复入选。改写转载或仅部分相似的文章仍需人工复核
- 原文确有署名才记录作者；“编辑”“责任编辑”不会代替作者，未署名就记“未署名”
- 文章按**原页刊发日期**归档：内置媒体按北京时间；自定义媒体保留原页日期/时区；补采的截图时间是实际采集时刻，不伪装成历史截图
- 截图来自 Chromium 访问原媒体网页并截取整页，不生成文字卡片。拒访、robots 限制、无可见正文、浏览器失败会记为失败；失败不算达标
- 实际不足 5 篇、历史栏目不完整、截图缺失都会显示缺口。不会编造文章/链接/作者，也不会用普通新闻硬补

## 自动计划是什么

默认两个自动开关都关闭。每日默认 **20:00，北京时间**，可在页面修改每日时间/时区；周报固定 **每周四 14:00，北京时间**。

周四周报覆盖此前 7 个完整自然日：前一周四至本周三，不含发送当天。例如 2026-10-08 的周报覆盖 2026-10-01 至 2026-10-07。周报任务会先尝试补齐该范围，再发送已有真实结果，缺口写入邮件和 Excel。栏目可能只暴露最新若干篇，补采不保证完整。

**电脑必须开机、联网、不休眠，且本程序持续运行。** 关闭浏览器标签页通常不影响仍运行的启动窗口；关闭启动窗口会停止所有任务。程序不设置 Windows 计划任务、不修改开机启动。不在线时不会神奇运行。

- 当天每日计划时间已过，重新打开可补执行当天一次
- 仅周四当天会自动启动周报；错过周四请手动选择本期范围导出/发送，不会在周五静默补发旧邮件
- 失败/中断任务需要查看记录后手动重试；不无休止重试、不反复调用付费 API
- SMTP 对同一收件地址、相同日期范围有持久化防重复保护。发送超时可能意味着服务器已收到，程序会标为不确定并阻止盲目重发。请先在邮箱核对

## 邮箱配置

填写邮箱提供商的 SMTP 主机、端口、SSL/TLS 或 STARTTLS、登录账号、授权码、发件地址和一个收件地址。一般使用邮箱专用授权码，而不是网页登录密码。本版不支持邮箱 OAuth 登录。

不启用自动周报时，也可以点击“邮件发送”并核对收件人和日期后手动发送。邮件是**两个附件**：`.xlsx` 元数据表和按日期分目录的截图 `.zip`（含 manifest 清单）。按最终 MIME 编码后大小检查上限，默认 20MB；超限不会偷偷丢图或自动上传第三方网盘，只提示本地下载或缩小范围。SMTP 接受不等于收件人已阅读。

密码/API Key 只在本机界面输入，**不要发到聊天、GitHub、截图或源代码**。默认只保存在运行内存，重启后需重填。勾选“保存到 Windows 凭据管理器”后才写入系统凭据库；不可用时会报错，不退回明文文件。无人值守重启后的自动 API/邮件需要你授权的安全持久化凭据。

## 可选 API 和一句话反馈

在本机填 HTTPS Base URL、供应商当前可用的模型名和 API Key，再启用。兼容文本 Chat Completions（Base URL 后会追加 `/chat/completions`）。不预设你有余额，不会替你充值。

- API 仅辅助判断没有明确栏目标签的候选是否属于时评，不凭空生成新闻元数据
- “用一句话调整偏好”可提出包含/排除关键词、补充栏目网址的变更。会先显示建议，点“应用”后才持久化；也可直接手工填规则
- 反馈功能不是能自我改写代码的代理；不能改邮箱/密钥/计划，不能执行 shell 或模型生成的 Python/JavaScript
- 反馈、近期已采集的公开标题/链接/失败记录和候选公开文章内容会发给你配置的 API；不要在反馈里粘贴密码、私密资料。失败请求也计入本机每日调用限制，且供应商可能收费。本机次数上限不是账单金额保证
- 关键词“包含”是任一关键词命中才保留；排除词任一命中就剔除

## 文件在哪里

默认就在工具目录的 `data/`：SQLite 保存普通设置、元数据、任务结果与规则建议；`screenshots/日期/` 保存 PNG；`exports/` 保存每次生成的两个附件。导出不会带 API Key、SMTP 密码、其他 LocalDesk 项目或聊天。普通本机数据没有加密，请保护电脑账号。备份请先关闭程序，再复制整个 data 目录。

更新代码前备份 data。本版使用独立数据库，不会读取/迁移旧 LocalDesk 的项目、聊天、资料或密码。

## 分发给别人 / GitHub 开源

现在可把干净的源码包发给别人按上述步骤运行。请不要连同自己使用后的 data、截图、导出件、凭据或 `.venv` 一起分享。

面向不懂 Python 的人，建议先生成并验收 Windows 便携版：

1. 在 Windows 上双击 `tools/build_windows.cmd`，或把已审阅的代码放到你指定的 GitHub 仓库后，手动运行 `Build Windows portable (manual)` Actions
2. 构建会打包 Python 应用和 Chromium，体积较大；生成 `dist/NewsDesk/NewsDesk.exe`。分发整个 NewsDesk 文件夹，不能只拷贝 exe
3. 必须在干净 Windows 电脑完成 [发布验收单](docs/RELEASE_CHECKLIST.md) 后，才能称为可分发成品。代码签名和 Windows 安全提示需发布者自行处理，不能要求用户关闭安全防护

初始 Windows 构建已通过，附加的成品 EXE/打包 Chromium/空白界面冒烟以对应 Actions 实际结果为准。手动构建默认不发布；维护者勾选 publish_prerelease 后，仅在成品冒烟全部通过时创建同仓库 v0.2.0-rc1 预发布及校验文件。已有同名标签或 Release 会中止，不覆盖。公开仓库的代码、日志与产物可公开可见。
